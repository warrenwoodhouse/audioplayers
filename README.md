# examples
* [Cassette Player](https://warrenwoodhouse.github.io/audioplayers/cassetteplayer): This audio player widget allows you to listen directly to a 70s and 80s mixtape playlist that I’ve created. This audio player uses CSS and JavaScript to showcase the playlist in a custom built audio player in the style of an 80s Cassette Player. 
* [Mass Effect N7 Audio Player](https://warrenwoodhouse.github.io/audioplayers/masseffect): This audio player widget allows you to listen directly to music from the Mass Effect franchise from a playlist I’ve created. This audio player uses CSS and JavaScript to showcase the playlist in a custom built audio player in the style of the N7 Screen Monitors found aboard the SSV Normandy SR-2.
* [Mass Effect Theme Songs Omni-Tool Audio Player](https://warrenwoodhouse.github.io/audioplayers/masseffect/themesongs): This audio player widget allows you to listen directly from the Theme Songs playlist I’ve created and using CSS and JavaScript to showcase the playlist in a custom built audio player in the style of the Omni-Tool Media Player hub.
